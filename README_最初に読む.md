# ジム管理アプリ Ver.0.2（学生配布用）

## 起動

1. すべての `.py` ファイルを同じフォルダーに置きます。
2. VSCodeでこのフォルダーを開き、ターミナルを開きます。
3. `py main.py`（Windows）または `python main.py` を実行します。
4. 数字のメニューから操作します。終了は `0` です。

Python標準ライブラリのみ使用。ネット接続、外部パッケージ、データベースは不要です。

## 機能

- 会員一覧／新規会員登録／会員ID検索
- ワークアウト履歴／ワークアウト追加／会員別の累計運動時間

登録済みの会員は `M1001`・`M1002`・`M1003` です。
初期データはアプリ起動時に読み込まれ、**終了時には保存されません**。動作検証をやり直すときは、アプリを再起動してください。

## ファイルの役割

- `main.py`：メニューと処理の呼び出し、試験用の初期データ
- `models.py`：会員とワークアウト記録のデータ構造
- `member.py`：会員管理処理（課題1の読解対象）
- `workout.py`：ワークアウト管理処理（課題2の修正対象）
- `billing_plan.py`：課題3のコメント記入欄。実行はしません。
- `課題問題.md`：問題文
- `解答用紙.md`：課題1と課題2の回答欄

**注意**：`member.py` は変更せずに読解してください。`workout.py` は修正対象です。

## 模擬試験でのバージョン比較

このフォルダーは 抽象化版 です。両版は同じ操作・初期データ・不具合を持ちます。課題1の対象である `member.py` の命名と、それに伴う `main.py` の呼び出し名だけが異なります。
